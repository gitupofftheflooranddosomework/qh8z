# Security policy

## Supported version

Until qh8z has multiple maintained release lines, security fixes target the current production release on `main`. Old deployments should be upgraded to the latest supported production release rather than assumed to receive separate patches.

## Reporting a vulnerability

Please report suspected qh8z security vulnerabilities privately to:

`security@qh8z.com`

Include, when available:

- the affected qh8z URL, API endpoint, or component;
- a clear description of the issue and impact;
- minimal reproduction steps or proof of concept;
- whether any real user data was accessed or modified;
- suggested remediation, if known; and
- a safe way to contact you.

Do **not** include passwords, API keys, session cookies, payment-card data, or unrelated personal information in the report.

## Safe research expectations

Good-faith research should:

- use accounts and data you own or are authorized to test;
- avoid accessing, modifying, deleting, or retaining another user's data;
- avoid phishing, social engineering, malware distribution, spam, denial-of-service, or destructive testing;
- stop testing and report promptly if you encounter non-public user data;
- avoid automated traffic that materially degrades service for other users; and
- allow qh8z reasonable time to investigate and remediate a confirmed issue before public disclosure.

If testing could create material availability risk, contact qh8z first to arrange a safe test window.

## What qh8z will do

For a credible report, qh8z will aim to:

- acknowledge receipt through a private channel;
- reproduce and assess severity;
- contain active exploitation where possible;
- develop and test a remediation;
- rotate affected credentials when needed;
- document the incident timeline; and
- coordinate disclosure with the reporter where appropriate.

No bounty or payment is promised unless qh8z explicitly establishes a bounty program for the reported issue.

## Public launch requirement

`security@qh8z.com` must be operational and monitored before qh8z.com is declared publicly launched.
